# 🍔 The Perfect Burger
> Cinematic Culinary Science, Digitally Engineered.

Welcome to **The Perfect Burger**, a premium interactive frontend experience. This project bridges educational storytelling with tactile gameplay through physics-based scroll mechanics and fluid drag-and-drop interactions. 

## ✨ The Experience
- **Cinematic Pacing:** Spaced out beautifully with massive, restricted-width typography that ensures breathing room, following high-end Awwwards UI principles.
- **GSAP Scroll-Locked Drops:** Uses advanced GSAP `ScrollTrigger` to pin stages. When a correct drop sequence is completed, physics unpin everything—animating the ingredient downward into a globally sticky central burger stack.
- **Flawless DnD Interaction:** Fluid and snappy drag-and-drop ingredient selection using `@dnd-kit/core`.

## 🛠 Tech Stack
- **Framework:** React + Vite
- **Motion & Physics:** GSAP, `@gsap/react`, `@dnd-kit/core`
- **Styling:** Tailwind CSS (Strictly enforcing no empty space and cinematic paddings)
- **Typography:** Cabinet Grotesk 

## 🚀 Getting Started

Clone the repository and jump into the creative flow instantly.

```bash
# Clone the repository
git clone https://github.com/BurairAbbas29/burger-web.git

# Navigate into the directory
cd burger-web

# Install all dependencies (GSAP, Tailwind, DnD)
npm install

# Start the high-speed Vite dev server
npm run dev
```

## 🌐 Deployment
Because it relies entirely on Vite and static client-side rendering for its scroll physics, deploying this app requires zero heavy lifting.

Simply import your repository into **Vercel** and deploy using the standard Vite presets. It is optimized to perform flawlessly on edge networks.
